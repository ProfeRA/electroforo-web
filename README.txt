ELECTROFORO - APLICACIÓN WEB

Estructura:
- index.html
- css/styles.css
- js/app.js
- assets/logo-electroforo.png

Abrir index.html en un navegador para probar la aplicación.

Incluye:
1. Presentación del logo a pantalla completa/responsive.
2. Sección de servicios informáticos.
3. Formulario de reservas/visitas/presupuestos.
4. Catálogo de insumos y repuestos.
5. Carrito con persistencia en localStorage.
6. Diseño responsive para PC, tablet y celular.

Para pasar a producción:
- Reemplazar los productos de ejemplo en js/app.js por el catálogo real.
- Configurar precios y stock.
- Conectar el formulario a WhatsApp, email o backend/base de datos.
- Configurar el medio de pago si se desea vender online.
- Cambiar el email de contacto de index.html.
